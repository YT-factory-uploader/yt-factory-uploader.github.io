Privacy Policy

Effective date: November 16, 2026

YT Factory Uploader (“the tool”) is a personal program that runs only on its owner's computer and uploads videos to YouTube channels that the owner owns. This policy explains what data the tool accesses and how it is handled.

Who uses the tool

The tool has a single user: its owner. It is not offered to the public, and it only connects to YouTube channels that belong to the owner.

Data the tool accesses

When a channel is connected through Google sign-in (OAuth 2.0), the tool requests two permissions:

  • youtube.upload — to upload videos and thumbnails to that channel and set their title, description, tags, category, language and scheduled publish time;
  • youtube.readonly — to read basic information and statistics of that channel (channel ID, title, handle, account status such as permission to upload long videos, and channel statistics).

The tool does not access data of any other users or channels, does not read comments, subscribers' personal data, emails, contacts or any other Google account data.

How the data is used

The data is used only to upload the owner's videos to the owner's channels, to confirm that the correct channel is connected, and to check whether the channel can accept a given upload. It is not used for advertising, profiling or any other purpose.

Storage and sharing

  • OAuth access and refresh tokens are stored only on the owner's computer, in a local folder that is not uploaded anywhere or included in version control.
  • The tool keeps a local log of its own uploads (video IDs, titles and scheduled publish times) on the same computer.
  • No data is sent to any server other than Google's / YouTube's own APIs.
  • Data is never shared, transferred or sold to anyone.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Tokens and the local upload log are kept until the owner deletes them or disconnects the channel. Deleting the token file removes the tool's access data from the computer.

How to revoke access

Access can be revoked at any time on the Google Account permissions page: myaccount.google.com/permissions — choose “YT Factory Uploader” and remove access. After that the stored tokens stop working.

YouTube API Services

The tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

This website

This website is a static page. It does not use cookies, analytics or forms and does not collect any personal data. It is hosted by GitHub Pages.

Changes

If this policy changes, the updated version will be published on this page with a new effective date.
