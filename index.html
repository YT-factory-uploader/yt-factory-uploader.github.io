YT Factory Uploader

A personal tool that uploads videos to my own YouTube channels through the YouTube Data API v3.

What it is

YT Factory Uploader is a small private program that runs only on my own computer. I produce long-form videos for several YouTube channels that I own, and this tool publishes them: it uploads each finished video, sets its title, description, tags and thumbnail, and schedules the publication time.

It is not a public service. There are no other users, no sign-up, and it never accesses channels that do not belong to me.

How it uses YouTube API Services

  • Uploads videos (videos.insert) and sets thumbnails (thumbnails.set) on my channels.
  • Reads basic information and statistics of my own channels (channels.list), for example to check that the right channel is selected and that it is allowed to upload long videos.
  • Marks every upload as containing altered or synthetic content: the narration uses a text-to-speech voice.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
